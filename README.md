# LinkedIn Assistant

A Python-based automation tool to find newly joined LinkedIn members and send them personalized messages.

## Features

- Detect newly joined members using LinkedIn member ID numbers
- Message composition with templates
- City and district filtering
- Browser automation with Playwright
- Automatic GitHub repository refresh every 48 hours

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Launch with: `LinkedIn Asistan.cmd`

## GitHub Repository

Repository: https://github.com/akanturker-dev/linkedn

48-hour automatic refresh protocol is implemented via `git-refresh.ps1` script.
